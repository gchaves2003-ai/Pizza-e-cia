#  Pizza & Cia - Sistema Ágil de Pedidos

O **Pizza & Cia** é uma aplicação web interativa desenvolvida com foco em **usabilidade (UX/UI)**, **desempenho** e **otimização do tempo de atendimento** em estabelecimentos alimentícios. 

O objetivo do projeto é demonstrar o domínio de conceitos fundamentais do desenvolvimento web client-side (Front-end Vanilla) e manipulação dinâmica de estado através da manipulação do DOM.

---

##  Funcionalidades

* **Cardápio Dinâmico:** Exibição de produtos renderizados dinamicamente via JavaScript com dados estruturados.
* **Observações por Item:** Permite ao cliente adicionar personalizações específicas (ex: "sem cebola", "massa fina") individualmente antes de adicionar o item ao carrinho.
* **Gerenciamento do Carrinho:**
  * Adição e acúmulo de múltiplos itens.
  * Remoção individual de itens selecionados.
  * Atualização e cálculo automático do valor total.
* **Validação de Interface:** Botão de finalização habilitado apenas quando há itens ativos no carrinho.
* **Layout Responsivo:** Interface otimizada para desktops e dispositivos móveis (Mobile First Design).

---

##  Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da aplicação.
* **CSS3:** Estilização responsiva com Flexbox, CSS Grid e Variáveis CSS para padronização visual.
* **JavaScript (ES6+):** Manipulação dinâmica do DOM, gerenciamento de estado local do carrinho e eventos.
